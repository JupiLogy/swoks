Welcome to the SWOKS repo!

## What is SWOKS?
SWOKS is a module that "listens" to your neural network and detects when changes are happening. I designed it with Reinforcement Learning in mind, but it can be used for other paradigms.

## What does SWOKS stand for?
Sliced Wasserstein Online Kolmogorov Smirnov: it's a mouthful, but it's named after some great scientists whose foundational works made the algorithm possible.

## Where can I learn more?
Read the [SWOKS paper](https://arxiv.org/abs/2405.19047), as presented at COLLAs 2024!
